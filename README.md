# Unplugged Retreat

A responsive, multi-page marketing website for a fictional retreat company focused on helping remote workers disconnect from burnout and reconnect through nature, collaboration, and creativity.

**[Live Demo](https://anjie-mf.github.io/Unplugged/)**

---

## About the Project

This project was built as part of my front-end development training to strengthen my understanding of responsive web design, layout systems, and multi-page site structure.

The goal was to build a polished marketing website using foundational front-end tools rather than relying on frameworks. I focused heavily on mobile-first CSS, Flexbox layouts, and creating a consistent user experience across devices.

---

## Pages

- **Home** — Hero section, retreat benefits, featured amenities, and community-focused branding
- **About** — Company mission, retreat philosophy, and supporting imagery
- **FAQ** — Common questions presented in an organized responsive layout
- **404 Page** — Custom error page for missing routes

---

## Built With

- **HTML5** — Semantic page structure
- **CSS3** — Custom styling and responsive layouts
- **Flexbox** — Section alignment and layout behavior
- **JavaScript** — Minimal scripting
- **Git & GitHub** — Version control and deployment
- **Google Fonts** — Custom typography
- **Normalize.css** — Cross-browser consistency

---

## Features

- **Responsive design** across mobile, tablet, and desktop breakpoints
- **Mobile-first CSS workflow**
- **Multi-page site architecture**
- **Flexbox-based layouts**
- **Consistent branding and typography**
- **Custom 404 page**
- **Reusable navigation and footer structure**

## What I Learned

- Structuring and organizing a multi-page website
- Building responsive layouts with Flexbox instead of relying on frameworks
- Using media queries to progressively scale layouts for larger screens
- Debugging layout issues caused by inherited styles and spacing conflicts
- Why mobile-first development creates cleaner, more maintainable CSS
- Managing assets and file organization in a growing project
